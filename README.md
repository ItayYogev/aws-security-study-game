## תוכן הגרסה

תמונת המקור המעודכנת מתאריך **20.10.2026**: 49 פרקים ראשיים, 3,107 מקטעי טקסט ו־140 תמונות.

- **מסך לימוד פשוט:** בחירת נושא ומספר שאלות, שאלה אחת, ארבע תשובות, הסבר וציטוט. ברירת המחדל היא סבב אמריקאי של 10 שאלות.
- **259 שאלות אמריקאיות:** כולל 67 שאלות מנוסחות בעברית מתוך טבלאות השירותים ו־11 שאלות שירותי SRA. נוספו שאלות על עדכוני StackSets, יצירת OpsItem דרך EventBridge והסיכון ש־Service Catalog מצמצם. לכל 49 הפרקים יש שאלות גם במסלול ברירת המחדל.
- **526 כרטיסיות שליפה:** ניסוח ייעודי לכל נושא ולכל תמונת הבנה. קטעים קצרים מאותו נושא אוחדו לכרטיסיה עם ציטוט רציף, במקום שאלות חוזרות שנבחרו לפי מילות מפתח. הכרטיסיות זמינות תחת ״אפשרויות נוספות״; ההערכה עצמית.
- **ציטוט ממוקד:** שיוכי השאלות האמריקאיות למקטעי המקור מפורשים ונבדקים בבנייה; אין בחירה אוטומטית של הציטוט לפי חפיפת מילים.
- **שירותים בתרשים SRA:** גם שירותים שמופיעים בשם בלבד נכללו, כגון Audit Manager, Private CA ו־VPC Lattice. בשאלות אלו מצוטט השם מהתרשים, והסבר התפקיד מסומן כהרחבת ידע נפרדת, לא כהגדרה שנכתבה במסמך.
- **תרשימים וממצאים:** 50 תמונות שנבחרו להבנה; לא שאלות על לחיצה או הגדרת מסכים.
- **ספריית מקור:** כל 140 התמונות וכל הטקסט, כולל הוראות היישום שהוצאו מהמשחק.
- **חזרה ושמירה:** סינון שירותים, טעויות, כוכבים, המשך סבב, יצוא ויבוא גיבוי.

הוראות Console, פקודות CLI ורצפי הקמה אינם נדרשים במשחק. הגדרות מהותיות שנמצאו בתוך מדריכים נשמרו ללמידה. [ביקורת הכיסוי](./coverage-audit.json) מפרטת לכל מקטע מקור את הסיווג, סיבת הסיווג ושיוכו. מספרי המקטעים הם מזהי הייצוא, לא עמודי המסמך.

**הבחנה חשובה:** שימור המקור אינו הוכחה שכל משפט נבדק בשאלה אמריקאית. כל יחידת ידע מסווגת מקבלת שאלת שליפה בהערכה עצמית; השאלות האמריקאיות הן מסלול נוסף. המונים המדויקים והעדכניים מופיעים במשחק ובקובץ הביקורת.

## שימוש בטלפון ומצב לא מקוון

האתר מתארח ב־GitHub Pages כאתר סטטי, ללא שרת יישום וללא אנליטיקה. נדרש חיבור לרשת לטעינת האתר; הטעינה הראשונה כוללת קובץ גדול עם תמונות מוטמעות.

להפעלה ללא רשת, הורד את [קובץ HTML העצמאי](./AWS-Security-Study-Game.html) ופתח בדפדפן התומך בקבצים מקומיים. התנהגות פתיחת HTML מקומי תלויה במכשיר ובמערכת ההפעלה. אין הבטחה שהאתר המקוון יישאר זמין ללא רשת, ואין Service Worker.

ההתקדמות נשמרת ב־localStorage באותו דפדפן ואותו אתר. היא אינה מסתנכרנת אוטומטית בין מחשב לטלפון, או בין הקובץ לאתר. אפשר להעביר גיבוי בין עותקים מאותה גרסה דרך מסך ״התקדמות״.

במעבר לגרסה הפשוטה מועברת אוטומטית התקדמות בשאלות אמריקאיות שמזהיהן לא השתנו, מהגרסה הקודמת של מקור זה. כרטיסיות מאוחדות וסבבים מתחילים מחדש, עם הודעה מפורשת. השמירה הקודמת נשארת ללא שינוי. גיבויי גרסה 3 אינם מיובאים כגיבויי גרסה 4; קובץ לא תואם נדחה עם הסבר, בלי למחוק התקדמות.

## ציטוטים ודיוק מקצועי

בכל תשובה מוצג ציטוט מקור. בשאלת תמונה המקור הוא התמונה עצמה והטקסט הסמוך, אם קיים; בשאלת הגדרה מתוך טבלה מוצג גם תמלול ההגדרה.

זהו חומר לימוד אישי, לא מוצר AWS רשמי ולא בנק שאלות בחינה. הטקסט המקורי נשמר גם כאשר הטענה בו אינה מדויקת או התיישנה. הערות תיקון מופיעות בנפרד מהציטוט. **לא בוצעה בדיקת עובדות מלאה מול תיעוד AWS עדכני.** במיוחד יש לבדוק מגבלות, תמחור, שינויים בשירותים וטענות פרישה; ציון גבוה אינו הוכחה למוכנות למבחן.

המשחק עצמו אינו דורש התקנת Python או ספריות.

לבנייה חוזרת ב־PowerShell, לאחר התקנת Python:

```powershell
python -m pip install -r .\requirements.txt
$env:PYTHONIOENCODING = 'utf-8'
python .\build_game.py
python .\test_game.py
```

המחולל נועל את ה־SHA-256 של צילום המקור שנבדק. לעדכון עתידי יש לבדוק את **כל השינויים**, את תחומי How-to, את חריגי הסיווג ומספרי התמונות, את סדר 493 קבוצות הנושאים ואת שיוכי הציטוטים, לעדכן שאלות ותמלולים, ורק אז לעדכן את ה־hash ולבנות. `-` ברשימת השליפה מציין קבוצת ניווט או הקדמה שסווגה כהקשר בלבד; התוכן נשאר בארכיון. החלפת המקור ללא ביקורת נעצרת בשגיאה; אין סנכרון אוטומטי עם Google Docs.

הפרסום: GitHub Pages מתוך `main`, תיקיית השורש. הקובץ `.nojekyll` מאפשר הגשה סטטית ללא עיבוד Jekyll.
