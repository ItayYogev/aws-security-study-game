## תוכן הגרסה

תמונת המקור המעודכנת מתאריך **20.10.2026**: 49 פרקים ראשיים, 3,112 מקטעי טקסט ו־140 תמונות.

- **מסך לימוד פשוט:** בחירת נושא ומספר שאלות, שאלה אחת, ארבע תשובות, הסבר וציטוט. ברירת המחדל היא סבב אמריקאי של 10 שאלות.
- **636 מושגים ושאלות אמריקאיות:** כל שאלה מציגה מושג ובודקת מה הוא או מה תפקידו. התשובות הן הגדרות, לא שמות שירותים, פקודות או מספרי מכסות. נכללו מושגי משנה, למשל סוגי מדיניות, סוגי הצפנה, רכיבי CloudWatch, בקרות Config ותפקידי ECS. לכל 49 הפרקים יש שאלות במסלול ברירת המחדל.
- **אותו מאגר בשליפה עצמית:** לכל מושג יש גם כרטיסיה עם אותה הגדרה ואותו ציטוט. זהו אופן תרגול חלופי, לא עוד 636 מושגים. אין יותר מסלול עם שאלות תפעוליות ישנות או שאלות כלליות שנוצרו לפי מילות מפתח.
- **ציטוט ממוקד:** שיוכי השאלות האמריקאיות למקטעי המקור מפורשים ונבדקים בבנייה; אין בחירה אוטומטית של הציטוט לפי חפיפת מילים.
- **שירותים בתרשים SRA:** גם שירותים שמופיעים בשם בלבד נכללו, כגון Audit Manager, Private CA ו־VPC Lattice. בשאלות אלו מצוטט השם מהתרשים, והסבר התפקיד מסומן כהרחבת ידע נפרדת, לא כהגדרה שנכתבה במסמך.
- **הגדרות מהתרשימים:** כל 67 ההגדרות המתומללות ו־11 שמות שירותי SRA משויכים במפורש למושגים. כאשר שירות מופיע גם בטקסט וגם בתרשים, מצורף מקור נוסף במקום שאלה כפולה. כל השרטוטים נשארו לעיון בסיכום המלא.
- **מסיחים:** שלוש הגדרות של מושגים אחרים, בעדיפות לאותה קטגוריה. רשימת אי־התאמה מפורשת מונעת שימוש בכינויים נרדפים או ביכולות חופפות כתשובות שגויות.
- **ספריית מקור:** כל 140 התמונות וכל הטקסט, כולל הוראות היישום שהוצאו מהמשחק.
- **חזרה ושמירה:** סינון שירותים, טעויות, כוכבים, המשך סבב, יצוא ויבוא גיבוי.

הוראות Console, פקודות CLI ורצפי הקמה אינם נדרשים במשחק. הגדרות מהותיות שנמצאו בתוך מדריכים נשמרו ללמידה. [ביקורת הכיסוי](./coverage-audit.json) מפרטת לכל מקטע מקור את הסיווג, סיבת הסיווג ושיוכו. מספרי המקטעים הם מזהי הייצוא, לא עמודי המסמך.

**ביקורת כיסוי:** כל 493 קבוצות הנושאים מהסקירה הקודמת קיבלו החלטה מפורשת: 446 משויכות ישירות למושגים, 36 משויכות למושגים שכבר מופיעים במקום אחר, ו־11 הוחרגו כניווט, פקודות, פרטי תמחור או פתיחות לרשימות. פיצול קבוצות שמכילות כמה מושגים יצר את מאגר 636 המושגים. מקור מצוטט יכול לכלול פרטים נוספים שאינם מושא השאלה. שימור כל משפט וכל תמונה אינו טענה שכל פרט תפעולי נבדק בשאלון.

### שינויים שנמצאו בייצוא האחרון

הושוו כל מקטעי הטקסט וכל התמונות מול הגרסה הקודמת; [דוח השינויים המדויק](./source-changes.json) כולל טקסט לפני ואחרי ומספרי מקטעים:

- Instance Profile הופרד למושג עם הסבר מפורש על הקשר בין Role למופע, STS, פרטי גישה זמניים ו־IMDS. השאלות בודקות תפקידים, ולא את מספר שעות התוקף.
- נוסף שם OpsItem ככותרת; הוסרו ההסברים הקודמים על ריכוז לוגים והוחלפו במנגנון עדכוני סטטוס דרך SNS ובשילוב Automation Runbooks. נוספו מושגים ייעודיים לשתי היכולות.
- עודכן ניסוח ההגדרה של S3 Presigned URL.
- עודכנו הכותרת והניסוח של API Gateway Execution Logs.
- כל 140 התמונות נשארו ללא שינוי. נוספו בסך הכול חמישה מקטעי טקסט.

## שימוש בטלפון ומצב לא מקוון

האתר מתארח ב־GitHub Pages כאתר סטטי, ללא שרת יישום וללא אנליטיקה. נדרש חיבור לרשת לטעינת האתר; הטעינה הראשונה כוללת קובץ גדול עם תמונות מוטמעות.

להפעלה ללא רשת, הורד את [קובץ HTML העצמאי](./AWS-Security-Study-Game.html) ופתח בדפדפן התומך בקבצים מקומיים. התנהגות פתיחת HTML מקומי תלויה במכשיר ובמערכת ההפעלה. אין הבטחה שהאתר המקוון יישאר זמין ללא רשת, ואין Service Worker.

ההתקדמות נשמרת ב־localStorage באותו דפדפן ואותו אתר. היא אינה מסתנכרנת אוטומטית בין מחשב לטלפון, או בין הקובץ לאתר. אפשר להעביר גיבוי בין עותקים מאותה גרסה דרך מסך ״התקדמות״.

גרסת המושגים משתמשת בשמירה נפרדת, `aws-security-lab-v5-concepts`. ההתקדמות מתחילה מאפס משום שהשאלות וההגדרות השתנו; הצלחה בשאלה תפעולית ישנה אינה נחשבת שליטה במושג חדש. אם נמצאה שמירה ישנה מוצגת הודעה מפורשת, והיא אינה משתנה או נמחקת. גיבויי גרסאות 3 ו־4 אינם מיובאים כגיבוי גרסה 5; קובץ לא תואם נדחה עם הסבר, בלי למחוק התקדמות.

## ציטוטים ודיוק מקצועי

בכל תשובה מוצגת הגדרה תמציתית ללמידה, ובנפרד ציטוט מקור שלא נוסח מחדש. בשירותים שמופיעים רק בתרשים מצוטטים ההגדרה המתומללת או שם השירות. שם בלבד אינו מוצג כאילו היה הגדרה מהמסמך; הרחבת הידע מסומנת בהתאם.

כל קטעי המקור מוצגים בכיוון RTL וביישור לימין, גם כשפסקה מתחילה באנגלית: בתשובות, בציטוטי תרשימים, בספריית הסיכום ובחלון המקור. הטקסט עצמו נשמר ללא שינוי; מילים באנגלית שומרות על סדר האותיות התקין.

זהו חומר לימוד אישי, לא מוצר AWS רשמי ולא בנק שאלות בחינה. הטקסט המקורי נשמר גם כאשר הטענה בו אינה מדויקת או התיישנה. הערות תיקון מופיעות בנפרד מהציטוט. **לא בוצעה בדיקת עובדות מלאה מול תיעוד AWS עדכני.** במיוחד יש לבדוק מגבלות, תמחור, שינויים בשירותים וטענות פרישה; ציון גבוה אינו הוכחה למוכנות למבחן.

המשחק עצמו אינו דורש התקנת Python או ספריות.

לבנייה חוזרת ב־PowerShell, לאחר התקנת Python:

```powershell
python -m pip install -r .\requirements.txt
$env:PYTHONIOENCODING = 'utf-8'
python .\build_game.py
python .\test_game.py
```

המחולל נועל את ה־SHA-256 של צילום המקור שנבדק. לעדכון עתידי יש לבדוק את **כל השינויים**, למפות מחדש במפורש את מספרי המקטעים בקבוצות ובציטוטים, לסקור קבוצות או מושגים חדשים ואת חריגי הסיווג, ולעדכן הגדרות ותמלולים. רק אז מעדכנים את ה־hash ובונים. מזהי הקבוצות הם מזהי סקירה יציבים, ולא מספרי פסקה או כותרות שמתגלות אוטומטית. החלפת המקור ללא ביקורת נעצרת בשגיאה; אין סנכרון אוטומטי עם Google Docs.

הפרסום: GitHub Pages מתוך `main`, תיקיית השורש. הקובץ `.nojekyll` מאפשר הגשה סטטית ללא עיבוד Jekyll.
